# 听歌日记 · 网页采集

Chrome 扩展，用于记录 [Apple Music 网页版](https://music.apple.com/) 的播放，并可同步到 Android 听歌日记。与 AM++ 采集插件相互独立；网页记录先保存在浏览器本机。

## 安装

1. 下载并解压 `Listening-Diary-Web-Extension-v0.6.1.zip`，保留解压后的文件夹，里面应直接包含 `manifest.json`。
2. 在 Chrome 打开 `chrome://extensions`，开启右上角“开发者模式”，点击“加载已解压的扩展程序”，选择上述文件夹。
3. 打开或刷新 Apple Music 网页，正常登录并播放。点击工具栏的听歌日记图标可查看记录；可在扩展菜单中固定图标。

**已安装扩展的用户更新**：把新 ZIP 解压后的文件覆盖到原扩展目录，在 `chrome://extensions` 点击该扩展的重新加载，再刷新 Apple Music。保留原目录和扩展，避免本机记录与配对丢失。

## 与日记同步

1. 手机或平板覆盖安装听歌日记 v1.3，打开日记并进入“设置 → 多设备同步”，点“显示配对码”。
2. 电脑与日记设备保持网络互通。在扩展弹窗输入日记显示的局域网 IP 和六位配对码，点击“配对并同步”，按浏览器提示允许访问。
3. 配对一次后，网页播放记录会在日记打开且双方网络互通时自动同步。日记不在线时先存于浏览器，待设备可达后自动补传。切换网络或 IP 后会尝试已知地址；如果无法找到设备，可在弹窗中选择“更换连接”。

手机日记的“已同步设备”会显示直接连接过的网页采集端。不同网段、虚拟网卡或防火墙可能影响连接，设备时间应保持准确。网页记录会通过既有日记同步组传播，但网页端不会因浏览器关闭或网页无法采样而记录播放。

## 使用说明

弹窗展示当前歌曲、浏览器本机统计、最近记录及同步状态；打开期间按播放采样更新已听时长。暂停、拖动进度和缓冲不会按跳过的时间计入。网页休眠或后台限制可能造成少计；不要同时在多个 Apple Music 页面播放相同内容，以免重复计数。网页采集暂不获取 Windows 实际播放设备。

弹窗还支持导出日记导入文件和网页预览备份。卸载扩展会清除浏览器本机数据，卸载前请先同步或导出。旧预览版只有累计时长、缺少准确分段的记录，不包含在日记导入文件中。

## 开发测试

需要 Node.js。运行 `npm ci`，再运行 `npm test`。扩展使用 Chrome Manifest V3，按已观察的播放进度统计；不同 Apple Music 网页版本或浏览器环境可能影响采集。
