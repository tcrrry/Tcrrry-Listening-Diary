# 听歌日记 · 采集器 v1.0

配合听歌日记 App 使用，在 AM++ 运行期间记录播放并同步到本机日记。启用采集器后不需要一直打开日记 App；记录不会上传到服务器。

## 使用

1. 安装听歌日记 v1.0，在设置中连接并授权本机 AM++。
2. 在 AM++ 覆盖导入采集器 ZIP，启用插件；保留原插件及数据，不要先卸载或清除数据。
3. 正常播放后，记录通常每 15 秒保存并同步；插件面板也可立即补传。断连时会保留待同步记录。

旧插件和日记的 JSON 备份可在 App 设置中导入。App 也可导出完整备份用于迁移，或按日期导出 CSV / TXT 供查看与分享。

## 记录与兼容性

只累计实际播放时间；暂停、缓冲和拖动不计入。有效播放门槛为 30 秒或歌曲时长一半，取较小值。未观察到的播放无法补算；强制停止可能丢失最近一小段。

原生播放观察器针对 Apple Music 1609 和 1613；其他版本使用 MediaSession 备用方式，设备、音量和部分播放信息能否取得取决于系统和播放器提供的数据。未记录的设备信息不会凭空补出。

插件 ID、数据目录和同步游标与此前版本保持一致。备份含详细听歌记录，请自行妥善保管。
